# PAS AI Quest automated coverage matrix

Status meanings:

- `EXISTING_SQL_API_COVERAGE`: executable lower-level SQL/API coverage exists.
- `EXISTING_FRONTEND_UNIT_COVERAGE`: executable component/unit coverage exists.
- `EXISTING_PLAYWRIGHT_COVERAGE`: an existing executable browser journey covers the behavior.
- `NEW_EXECUTABLE_E2E`: a newly authored non-fixme E2E/API-session test is discoverable through `playwright.regression.config.ts`.
- `TEST_FIXME`: scenario design exists but is skipped and is not coverage.
- `DEFERRED`: product behavior is explicitly deferred.
- `BUSINESS_RULE_PENDING`: no behavior may be assumed.
- `CYCLE_ADMIN_PENDING_IMPLEMENTATION`: BA-015 is frozen, but the UI-dependent scenario is not executable until the frontend exists. This is **not** counted as covered.
- `IMPLEMENTATION_GAP`: frozen/target behavior has no current endpoint/product implementation.
- `PERSISTENCE_AUTOMATION_PENDING`: lower-level pieces may exist, but restart orchestration is not executable.
